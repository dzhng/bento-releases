# Bento for Mac — releases

Signed builds of the Bento Mac app. This repository holds release files only;
the source is private.

- **Download:** <https://updates.bento.ing/mac/download> (the latest install kit)
- **Updates:** installed apps check <https://updates.bento.ing/mac/appcast.xml>
  and update themselves through Sparkle.

Each release lists the install kit (`Bento-macos-arm64.zip`), the signed update
archive, the appcast, `SHA256SUMS` and a `release.json` receipt naming the
source revision it was built from.
